* 攻击模型与机理：靶点服务为同核 CPU0 上执行 40,000 轮自旋的 HTTP 进程；未熔断时靶点持续以 180 req/s 自旋消耗 76% CPU0 导致前台严重饥饿；开启熔断后，内核在网络协议栈排队规则（qdisc/cls_bpf）层直接提前丢弃 972 个 TCP 报文（SYN 连接被阻断），靶点服务处理 0 个 HTTP 请求且处于 epoll_wait 空闲休眠（CPU 占比 0.0%），CPU0 完全释放给前台业务。
