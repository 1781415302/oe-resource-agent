# 加权 Agent 实验数据（正式两轮）

当前版本不设置 p99 和 EPS 性能达标线。默认延迟权重60%、吞吐权重40%，以完整HDR p99及实际RPS/EPS相对现场基线进行几何加权。

本次为2轮、8场景、默认与加权Agent两组，共32次试运行，每次3个完整5秒窗口。每轮窗口先取中位数，再计算轮间均值及样本SD。N=2仅作描述性比较。

正式数据按用户要求只选最先完成的两轮，额外第三轮另存原始目录，未用于此表。场景、权重与代码来源信息保存在study.json。
